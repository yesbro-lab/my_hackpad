# My Hand-Wired Hack Club Macropad

This is my custom 3-key mechanical macropad layout designed for the Hack Club Blueprint grant! I will be 3D printing this enclosure and hand-wiring the switches directly to the controller inside.

## Case Details

* Fully designed in 3D CAD using **Onshape**.
* Features accurate **14mm x 14mm squares** for mechanical switch snapping.
* **1.5mm top plate thickness** to ensure proper hardware locking.

## Circuit Details

* Designed using **KiCad**.
* Features **3 mechanical push-button switches** and **3 RGB indicator LEDs**.
* Powered by a **Seeed Studio XIAO** microcontroller board.

* **1x** Seeed Studio XIAO RP2040 Microcontroller
* **3x** Cherry MX Mechanical Keyswitches
* **3x** WS2812B NeoPixel RGB LEDs
